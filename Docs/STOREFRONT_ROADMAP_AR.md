# خطة تطوير الواجهة — الوصول لمستوى المتاجر العالمية

آخر تحديث: 15-10-2026 · المرجع: Saleor Paper · Medusa · Next.js Commerce · Bagisto
**المنهج:** العقد أولاً (Contract-first) — نصمم ونبرمج على بيانات تجريبية بعقد API محدد، ثم يُستبدل المصدر عند جاهزية الباك اند.

## قواعد ثابتة
| # | القاعدة |
|---|---|
| R-1 | **وضع العرض التجريبي** `VITE_DEMO_FIXTURES=true`: يملأ الميزات التي لا API لها ببيانات تجريبية، ويُظهر شارة «عرض تجريبي» على كل قسم تجريبي. مفعّل في Staging والمعاينات فقط. **ممنوع في الإنتاج عند الإطلاق** (بند في قائمة ما قبل الإطلاق). |
| R-2 | بدون وضع العرض: كل ميزة بلا API **تختفي** تلقائياً (404/405 ← القسم مخفي). |
| R-3 | **لا تقييمات أو أرقام وهمية أمام الزبونات أبداً**. أرقام المخزون من `stock` الحقيقي فقط، والتقييم في JSON-LD من بيانات حقيقية فقط. |
| R-4 | **D-STORE:** متجر واحد أمام العميلة — لا أسماء متاجر موردة في أي واجهة أو رد. |
| R-5 | كل مرحلة تنتهي بـ: كود + اختبارات + ملف عقد API + برومت لعاصم + تحديث هذا الملف. |

الحالات: ⬜ لم يبدأ · 🔧 قيد التنفيذ · 👀 بانتظار المراجعة · ✅ تم (واجهة) · 🔌 تم ومربوط بالـ API

## المرحلة 1 — صفحة المنتج (التحويل)
| # | البند | الواجهة | عقد الـ API | الحالة |
|---|---|---|---|---|
| P1-1 | التقييمات والمراجعات بالصور | ملخص نجوم + توزيع + فلتر + قائمة بالصور + نموذج تقييم (للمشترية فقط) + تقييم على بطاقة المنتج | `GET /products/{slug}/reviews` · `POST /products/{slug}/reviews` (multipart) · `rating_avg` و`rating_count` في المنتج | 👀 |
| P1-2 | المتغيرات كأزرار بصرية (Swatches) | دوائر ألوان / أزرار أحجام بدل القائمة المنسدلة | `variants[].swatch_hex` · `variants[].image_url` (اختياريان) | 👀 |
| P1-3 | «باقي X قطع» | من `stock` أو `available_quantity` الحقيقي (≤ 5) | موجود | 👀 |
| P1-4 | «نبّهيني لما يتوفر» | نموذج رقم جوال عند نفاد المنتج | `POST /products/{slug}/stock-alerts` | 👀 |
| P1-5 | تبويبات المعلومات | الوصف · المكونات · طريقة الاستخدام · التفاصيل | `ingredients` · `how_to_use` · `specs[]` في رد المنتج | 👀 |
| P1-6 | مشاركة المنتج | مشاركة النظام / واتساب / نسخ الرابط | — | 👀 |

## المرحلة 2 — السلة والدفع (قيمة السلة)
| # | البند | الواجهة | عقد الـ API | الحالة |
|---|---|---|---|---|
| P2-1 | شريط التوصيل المجاني | «باقيلكِ ₪X للتوصيل المجاني» في السلة والدفع | `policies.free_delivery_threshold` (موجود) | 👀 |
| P2-2 | الكوبون | حقل في السلة والدفع + رسالة الخصم | `POST /cart/coupon` · `DELETE /cart/coupon` · `discount` في رد السلة | 👀 |
| P2-3 | «أضيفي معه» | منتجات مكمّلة في السلة (تعمل الآن بالمميّزة المتوفرة) | `GET /cart/suggestions` | 👀 |
| P2-4 | دفتر العناوين | حفظ/اختيار عنوان في الدفع + صفحة «عناويني» | `GET/POST/PATCH/DELETE /addresses` | 👀 |
