### سيناريوهات قاعدة البيانات

1. عميلان يحاولان حجز آخر قطعة معًا: حجز واحد ناجح والآخر تعارض، دون زيادة حجز المخزون.
2. عاملان ينظفان الحجز المنتهي معًا: تحرير مرة واحدة فقط.
3. إرسال الطلب نفسه بالمفتاح نفسه في عمليتين متزامنتين: رقم طلب واحد وخصم مخزون مرة واحدة.
4. عميلان ينشئان طلبين متزامنين: رقمان مختلفان وكميات مخزون صحيحة.
5. تشغيل `schedule:run` فعليًا: حذف الحجوزات المنتهية وإعادة المخزون المحجوز.
6. ترحيل بيانات قديمة بحالتي `pending_payment/paid`: تحويل إلى `pending/confirmed` مع حفظ معرفات الطلبات وإجمالياتها.

شُغلت MariaDB مؤقتة على `127.0.0.1:13316` في مجلد مستقل ثم أُغلقت بعد الاختبارات. قواعد المشروع الفعلية لم تُعدل. هذه نتيجة MariaDB؛ لم يُختبر Oracle MySQL مستقل أو ضغط طويل المدة.

## إصلاح OTP المكتشف

كان إدخال كود خاطئ في وضع الاختبار يؤدي إلى الرجوع إلى Redis. نُقل منطق وضع الاختبار إلى `OtpService::verify()` ليقبل `123456` ويرفض غيره محليًا، دون Redis أو HTTP خارجي. `send()` يعيد الكود الثابت مباشرة. لم يُضف SMS SDK أو متغير `SMS_PROVIDER`.

تؤكد `AuthTest` أن قيمة إعداد test_mode هي true والكود 123456، وتمنع الوصول إلى Redis أو HTTP غير المتوقع. `/auth/me` للمستخدم المصادق عليه ناجح، ولغير المصادق عليه يعيد 401. وضع الكود الثابت لا يختبر انتهاء صلاحية OTP الإنتاجي أو استهلاكه لمرة واحدة؛ ذلك خارج النطاق المحلي المعتمد.

## إعادة الاختبار

من مجلد Backend:

```powershell
& C:/xampp/php/php.exe artisan test --filter=AuthTest --no-coverage
& C:/xampp/php/php.exe artisan test --compact
```

من مجلد Frontend:

```powershell
$env:MVP0_TEST_PORT='8000'
npm run test:mvp0
npm test
npm run build:mvp0
npm run lint
```

اختبار HTTP ينشئ SQLite مؤقتة ويوقف خادمه عند الانتهاء. يجب أن يكون المنفذ 8000 فارغًا؛ لا يوقف خادمًا موجودًا عليه. منفذ إعداد المعاينة المعتاد في `.env.mvp0` لا يتغير بسبب اختبار HTTP المعزول.

سكريبت `backend/tests/closing-concurrency.php` يحتاج قاعدة MySQL/MariaDB جديدة وفارغة باسم `gazabella_closing_races` وإعدادات اتصالها عبر متغيرات البيئة، مع `APP_ENV=testing`, مفتاح اختبار `APP_KEY`, `CACHE_STORE=array`, `QUEUE_CONNECTION=sync`, `BROADCAST_CONNECTION=log`. يرفض العمل على اسم قاعدة آخر أو قاعدة تحتوي طلبات، ولا يحذف بيانات لإعادة الاختبار. مجموعة PHPUnit تدعم قاعدة اختبار منفصلة عبر `DB_CONNECTION=mysql` وباقي إعدادات الاتصال.

حزمة `backend-mvp0-changes-2026-09-26.zip` حُدثت إلى **32 ملفًا** وتشمل إصلاح OTP وphpunit.xml وسكريبت التزامن، مع بصماتها في `backend-mvp0-manifest.json`.

اختبار UX والشراء السريع موثق في تقرير التنفيذ السابق. لم يُرسل SMS أو تُنشأ دفعة تجارية أو يُنشر النظام على استضافة أثناء الإغلاق.
